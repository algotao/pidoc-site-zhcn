# Raspberry Pi 文档（中文版）

[项目站点](https://pidoc.cn) · [GitHub 仓库](https://github.com/algotao/pidoc-site-zhcn) · [更新记录](https://pidoc.cn/blog)

本仓库是 [Raspberry Pi 官方文档](https://www.raspberrypi.com/documentation/) 的中文翻译与本地化站点，同时收录 [GPIO Zero 文档](https://gpiozero.readthedocs.io/) 译文、Pico SDK API 参考，以及本站原创的常用操作、下载页等内容。译文按上游英文文档的 commit 增量同步，每次同步的上游版本与变更摘要记录在 [blog/release.mdx](blog/release.mdx)。

技术栈：Docusaurus 3.10（`@docusaurus/preset-classic`）、React 18、[Typesense](https://typesense.org/) 全文搜索；站点语言固定为 `zh-Hans`。需要 Node.js >= 18（见 [package.json](package.json) 的 `engines`）。

## 快速开始

```bash
npm ci            # 或 npm install；仓库带 package-lock.json
npm run start     # 本地开发服务器（热重载）
npm run build     # 生成静态站点到 build/
npm run serve     # 本地预览 build/ 结果
```

提交前建议至少执行一次 `npm run build`。配置中 `onBrokenLinks` / `onBrokenAnchors` 均为 `warn`，失效链接不会中断构建，请留意构建日志中的警告。

## 站点组成

- **两套文档实例**：主文档由 classic preset 提供，GPIO Zero 由 `docusaurus.config.js` 中额外的 `@docusaurus/plugin-content-docs`（`id: gpiozero`）提供，二者共用 `sidebars.js` 的自动生成侧边栏。
- **搜索**：站点搜索走 Typesense，前端配置在 `themeConfig.typesense`；请求通过 nginx 的 `/search-api` 同源反代，索引 collection 为 `pidoc`，并针对中文做了权重与容错参数调优。索引抓取和服务端部署不在本仓库内。
- **下载页**：`src/pages/downloads/` 中的镜像、Imager 链接指向外部 `https://dl.pidoc.cn/`，仓库不包含镜像文件；`pages.exclude` 已排除 `/imager/**`、`**/dl/**` 路径。
- **统计与 SEO**：`docusaurus.config.js` 注入 51.la、Clarity 脚本与站点验证 meta，并启用 sitemap。

## 构建与发布

线上站点部署在 `pidoc.cn` 的 nginx 静态目录，[pub.sh](pub.sh) 的流程是：清理 `build/` → `npm run build` → `rsync -avz ./build/ pidoc.cn:/data/docker/nginx/web/pidoc.cn/`。`docusaurus.config.js` 中的 GitHub Pages 字段仅为模板残留值。

注意 `pub.sh` 的 `set -e` 被注释，构建失败仍会继续 rsync，发布前请先手动确认 `npm run build` 成功。需要 `pidoc.cn` 的 SSH 权限；Typesense 索引抓取、镜像站 `dl.pidoc.cn` 均在本仓库之外单独维护。站点网络架构说明见 [`docs/pidoc/site_arch.mdx`](docs/pidoc/site_arch.mdx)。

## 贡献

1. Fork 仓库并新建分支，修改 `docs/`、`gpiozero/`、`blog/` 或 `src/` 下相应文件。
2. 遵循现有翻译风格与术语；新增页面确认 frontmatter 和侧边栏分组；涉及上游内容时说明对应来源与 commit。
3. 运行 `npm run build`（必要时 `npm run serve` 预览），确认无新增断链警告后提交 PR，描述变更并附预览截图。译文讨论与纠错可直接在 [Issues](https://github.com/algotao/pidoc-site-zhcn/issues) 提出。

## 常见问题

- **本地怎么验证？** `npm ci` 后 `npm run start` 实时查看；提交前 `npm run build`，用 `npm run serve` 检查生产构建。
- **新增页面没出现在侧边栏？** 检查 `draft`、`sidebar_position` 以及所在目录的 `_category_.json`；侧边栏由文件系统自动生成，无需改 `sidebars.js`。
- **搜索无结果或报错？** 检查站点侧 Typesense 服务、`/search-api` 反代与 `pidoc` collection 索引，本仓库只有前端搜索配置。
- **下载链接失效？** 版本号与链接集中在 `src/pages/downloads/`，实际文件托管在 `dl.pidoc.cn`，两边需分别更新。
- **构建缓存引起异常？** 执行 `npm run clear` 后重新构建。
