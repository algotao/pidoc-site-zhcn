# 摄像头模块 2

这款 800 万像素摄像头采用索尼 IMX219 传感器，分辨率为 3280 × 2464 像素。具备可调焦功能，最长曝光时间可达 11.76 秒。

## 变体

摄像头模块2提供以下版本：

* [**标准版**](https://www.raspberrypi.com/products/camera-module-v2/)。此版本仅捕捉可见光，红外光被滤除。
* [**无红外版**](https://www.raspberrypi.com/products/pi-noir-camera-v2/)。此版本未配备红外滤光片，可同时捕捉可见光与红外光。

有关本摄像头的详细硬件特性与功能说明，请参阅[硬件规格](./camera.mdx#hardware-specification)。
