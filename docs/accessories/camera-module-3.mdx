# 摄像头模块 3

这款 [1200万像素摄像头](https://www.raspberrypi.com/products/camera-module-3/) 采用索尼IMX708传感器，分辨率为4608 × 2592像素。具备[电动自动对焦](https://www.raspberrypi.com/news/new-autofocus-camera-modules/)功能，最长可支持112秒曝光时间。

## 变体

摄像头模块3提供以下版本：

* 标准版，常规视场角(FoV)
* 标准版，广角视场角
* NoIR版，常规视场角
* NoIR版，广角视场

标准型号仅捕捉可见光，红外光被滤除。NoIR型号未配备红外滤光片，可同时捕捉可见光与红外光。

所有这些版本也适用于独立的[摄像头模块3传感器组件](https://www.raspberrypi.com/products/camera-module-3-sensor-assembly/)。

:::tip
[现有证据](https://github.com/raspberrypi/libcamera/issues/43)表明摄像头模块3可能在CSI时钟频率谐波频率下产生射频干扰。该射频干扰频率范围可能干扰GPS L1频段（1575 MHz）。详情及建议的解决方法请参阅[Github讨论帖](https://github.com/raspberrypi/libcamera/issues/43)。
:::

## 摄像头模块 3 传感器组件

树莓派摄像头模块 3 传感器组件内置与摄像头模块 3 AF（自动对焦）相同的传感器和自动对焦功能，可让你把摄像头模块 3 的特性集成到更多样的外形规格中。

它以低成本为更小的设备增加成像能力，降低制造复杂度并缩短上市时间。

**规格**

* 索尼 IMX708 传感器
* 分辨率：1200 万像素
* 传感器尺寸：对角线 7.4 mm
* 像素尺寸：1.4 μm × 1.4 μm
* 水平 × 垂直：4608 × 2592 像素
* 标准版集成红外截止滤光片；NoIR 版不配备
* 相位检测自动对焦
* 工作温度：0°C 至 50°C
* 板载 EEPROM，用于存储摄像头数据
