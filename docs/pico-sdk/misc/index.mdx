# Miscellaneous

本章包含以下 API 分组：

- [boot_picobin_headers](./boot-picobin-headers.mdx): PICOBIN 格式的常量。
- [boot_picoboot_headers](./boot-picoboot-headers.mdx): RP2xxx 芯片在 BOOTSEL 模式下暴露的 PICOBOOT USB 接口的头部文件。
- [boot_uf2_headers](./boot-uf2-headers.mdx): RP2xxx 芯片在 BOOTSEL 模式下支持的 UF2 格式的头部文件。
- [pico_usb_reset_interface_headers](./pico-usb-reset-interface-headers.mdx): pico_stdio_usb 库可能暴露的重置接口的定义。
