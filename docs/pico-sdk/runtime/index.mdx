# Runtime

本章包含以下 API 分组：

- [boot_stage2](./boot-stage2.mdx): 负责初始化外部 flash 的第二阶段引导加载程序。
- [pico_atomic](./pico-atomic.mdx): C11 原子操作的辅助实现。
- [pico_base](./pico-base.mdx): Raspberry Pi Pico SDK 的核心类型与宏。
- [pico_binary_info](./pico-binary-info.mdx): Binary info 用于在 FLASH 中的二进制文件里嵌入机器可读信息。
- [pico_bootrom](./pico-bootrom.mdx): 访问 bootrom 中的函数与数据。
- [pico_bit_ops](./pico-bit-ops.mdx): 优化的位操作函数。
- [pico_cxx_options](./pico-cxx-options.mdx): 用于控制 C++ 相关编译选项的非代码库。
- [pico_clib_interface](./pico-clib-interface.mdx): 提供所使用的具体 C/C++ 运行时所需的胶水代码。
- [pico_crt0](./pico-crt0.mdx): 提供程序的入口/出口点。
- [pico_divider](./pico-divider.mdx): 由 RP2040 硬件除法器加速的优化 32 位与 64 位除法函数。
- [pico_double](./pico-double.mdx): 优化的双精度浮点函数。
- [pico_float](./pico-float.mdx): 优化的单精度浮点函数。
- [pico_int64_ops](./pico-int64-ops.mdx): 编译器内建 64 位乘法的优化替代实现。
- [pico_malloc](./pico-malloc.mdx): 为 malloc、calloc 与 free 提供多核安全保护。
- [pico_mem_ops](./pico-mem-ops.mdx): 提供编译器内建 memcpy、memset 及相关函数的优化替代实现。
- [pico_platform](./pico-platform.mdx): 用于 RP2 系列器件/架构的宏与定义（以及被非汇编代码包含时的函数），以便访问硬件。
- [pico_printf](./pico-printf.mdx): 由 Marco Paland 编写的 printf 精简替代实现（info@paland.com）。
- [pico_runtime](./pico-runtime.mdx): 为运行其他库提供的 main 前初始化器提供基础运行时支持。
- [pico_runtime_init](./pico-runtime-init.mdx): 在进入 main 之前搭建运行时环境所需的主要运行时初始化函数。
- [pico_stdio](./pico-stdio.mdx): 可定制的 stdio 支持，允许通过 UART、USB、半主机等方式进行输入输出。
- [pico_standard_binary_info](./pico-standard-binary-info.mdx): 包含可由 picotool 显示的二进制文件默认信息。
- [pico_standard_link](./pico-standard-link.mdx): 标准 SDK 可执行文件的链接选项设置。
- [pico_thread_local](./pico-thread-local.mdx): C/C++ 的 `__thread`/thread_local 支持。
