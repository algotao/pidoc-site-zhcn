通用输入/输出（GPIO）API。

### 详细描述

RP 系列微控制器有两组通用输入/输出（GPIO）引脚，分配如下：

RP2040 在 bank 0 中有 30 个用户 GPIO 引脚，在 QSPI bank 1 中有 6 个 QSPI 引脚（QSPI_SS、QSPI_SCLK 和 QSPI_SD0 至 QSPI_SD3）。QSPI 引脚用于从外部 flash 设备执行代码，因此用户 bank（GPIO0 到 GPIO29）供程序员使用。

可用 GPIO 引脚的数量取决于封装。QFN-60 封装（RP2350A）的 bank 0 中有 30 个用户 GPIO，QFN-80 封装（RP2350B）中有 48 个用户 GPIO。Bank 1 包含 6 个 QSPI 引脚和 USB DP/DM 引脚。

所有 GPIO 都支持数字输入和输出，但其中部分还可用作芯片模数转换器（ADC）的输入。GPIO 引脚到 ADC 的分配取决于封装。

RP2040 和 RP2350 QFN-60 的 GPIO ADC 引脚为 26-29。RP2350 QFN-80 的 ADC 引脚为 40-47。

每个 GPIO 可由运行在处理器上的软件直接控制，也可由多个其他功能块控制。

分配给每个 GPIO 的功能通过调用 `gpio_set_function` 函数来选择。

并非所有功能都在所有引脚上可用。

每个 GPIO 一次只能选择一个功能。同样，每个外设输入（例如 UART0 RX）一次只应在一个 *GPIO* 上选择。如果同一外设输入连接到多个 GPIO，外设将看到这些 GPIO 输入的逻辑 OR 值。有关 GPIO 功能选择的更多信息，请参阅数据手册。

### 类型定义

`typedef enum gpio_function_rp2040 gpio_function_t`<br/>&emsp;RP2040 上的 GPIO 引脚功能选择项（用作 `gpio_function_t` 类型定义）

`typedef enum gpio_function_rp2350 gpio_function_t`<br/>&emsp;RP2350 上的 GPIO 引脚功能选择项（用作 `gpio_function_t` 类型定义）

`typedef void(* gpio_irq_callback_t)(uint gpio, uint32_t event_mask)`<br/>&emsp;GPIO 事件的回调函数类型

### 枚举

`enum gpio_function_rp2040 { GPIO_FUNC_XIP = 0, GPIO_FUNC_SPI = 1, GPIO_FUNC_UART = 2, GPIO_FUNC_I2C = 3, GPIO_FUNC_PWM = 4, GPIO_FUNC_SIO = 5, GPIO_FUNC_PIO0 = 6, GPIO_FUNC_PIO1 = 7, GPIO_FUNC_GPCK = 8, GPIO_FUNC_USB = 9, GPIO_FUNC_NULL = 0x1f }`<br/>&emsp;RP2040 上的 GPIO 引脚功能选择项（用作 `gpio_function_t` 类型定义）

`enum gpio_function_rp2350 { GPIO_FUNC_HSTX = 0, GPIO_FUNC_SPI = 1, GPIO_FUNC_UART = 2, GPIO_FUNC_I2C = 3, GPIO_FUNC_PWM = 4, GPIO_FUNC_SIO = 5, GPIO_FUNC_PIO0 = 6, GPIO_FUNC_PIO1 = 7, GPIO_FUNC_PIO2 = 8, GPIO_FUNC_GPCK = 9, GPIO_FUNC_XIP_CS1 = 9, GPIO_FUNC_CORESIGHT_TRACE = 9, GPIO_FUNC_USB = 10, GPIO_FUNC_UART_AUX = 11, GPIO_FUNC_NULL = 0x1f }`<br/>&emsp;RP2350 上的 GPIO 引脚功能选择项（用作 `gpio_function_t` 类型定义）

`enum gpio_irq_level { GPIO_IRQ_LEVEL_LOW = 0x1u, GPIO_IRQ_LEVEL_HIGH = 0x2u, GPIO_IRQ_EDGE_FALL = 0x4u, GPIO_IRQ_EDGE_RISE = 0x8u }`<br/>&emsp;GPIO 中断电平定义（GPIO 事件）

`enum gpio_slew_rate { GPIO_SLEW_RATE_SLOW = 0, GPIO_SLEW_RATE_FAST = 1 }`<br/>&emsp;GPIO 输出的压摆率限制级别。

`enum gpio_drive_strength { GPIO_DRIVE_STRENGTH_2MA = 0, GPIO_DRIVE_STRENGTH_4MA = 1, GPIO_DRIVE_STRENGTH_8MA = 2, GPIO_DRIVE_STRENGTH_12MA = 3 }`<br/>&emsp;GPIO 输出的驱动强度级别。

#### gpio_irq_level

`enum gpio_irq_level`

GPIO 中断电平定义（GPIO 事件）

GPIO 中断电平

每个 GPIO 引脚可在以下 4 种情况下产生中断：

- 电平高：GPIO 引脚为逻辑 1

- 电平低：GPIO 引脚为逻辑 0

- 上升沿：GPIO 从逻辑 0 跳变为逻辑 1

- 下降沿：GPIO 从逻辑 1 跳变为逻辑 0

电平中断不会被锁存。这意味着，若引脚为逻辑 1 且电平高中断处于活动状态，则引脚变为逻辑 0 时该中断立即变为非活动状态。边沿中断保存在 `INTR` 寄存器中，可通过写入 `INTR` 寄存器清除。

**枚举值**

| 枚举值 | 说明 |
| --- | --- |
| GPIO_IRQ_LEVEL_LOW | GPIO 引脚为逻辑 0 时触发 IRQ。 |
| GPIO_IRQ_LEVEL_HIGH | GPIO 引脚为逻辑 1 时触发 IRQ。 |
| GPIO_IRQ_EDGE_FALL | GPIO 从逻辑 1 跳变为逻辑 0 时触发 IRQ。 |
| GPIO_IRQ_EDGE_RISE | GPIO 从逻辑 0 跳变为逻辑 1 时触发 IRQ。 |

#### gpio_acknowledge_irq

`static void gpio_acknowledge_irq (uint gpio, uint32_t event_mask) [inline], [static]`

确认当前核心上指定事件的 GPIO 中断。

**注意**：可以使用由 `gpio_irq_level` 中任意有效位组成的掩码调用此函数，但它对电平敏感中断无效——只要 GPIO 保持在指定电平，这类中断就一直处于待处理状态。处理电平敏感中断时，通常应先禁用该中断（参见 `gpio_set_irq_enabled`），待 GPIO 电平改变后再重新设置（或改为捕获相反的电平）。

**注意**：对于通过 `gpio_set_irq_enabled_with_callback` 或 `gpio_set_irq_callback` 设置的回调，此函数会被自动调用。

**参数**

- `gpio`: GPIO 编号
- `event_mask`: 要清除的事件位掩码。详见 `gpio_irq_level`。

#### gpio_set_irq_enabled_with_callback

`void gpio_set_irq_enabled_with_callback (uint gpio, uint32_t event_mask, bool enabled, gpio_irq_callback_t callback)`

便捷函数，一次性完成多项 GPIO IRQ 相关的初始化。

此方法混合了若干初始化操作，略显杂糅，具体包括：

- 根据使能标志，更新指定 GPIO 的指定事件是否会在调用它的核心上产生中断。

- 将调用它的核心的回调处理程序设为 `callback`（若 `callback` 为 NULL，则清除该处理程序）。

- 若 `enabled` 为 true，则使能当前核心上的 GPIO IRQ。

此方法通常用于一次性设置，之后其它 IRQ／事件通过 `gpio_set_irq_enabled` 使能。以这种方式在同一核心上添加的所有 GPIO／事件共用同一个回调；如需为不同 GPIO 设置多个相互独立的处理程序，应使用 `gpio_add_raw_irq_handler` 及相关函数。

此方法等价于：

**注意**：IO IRQ 在各处理器上相互独立。此方法只影响调用它的处理器。

```c
gpio_set_irq_enabled(gpio, event_mask, enabled);
gpio_set_irq_callback(callback);
if (enabled) irq_set_enabled(IO_IRQ_BANK0, true);
```

**参数**

- `gpio`: GPIO 编号
- `event_mask`: 将触发中断的事件。详见 `gpio_irq_level`。
- `enabled`: 使能／禁用标志
- `callback`: GPIO IRQ 发生时要调用的用户函数；若为 NULL，则移除该回调

可选择反转 GPIO IRQ 信号，或将其强制驱动为高电平或低电平

**参数**

- `gpio`: GPIO 编号
- `value`: 参见 `gpio_override`

#### gpio_set_mask

`static void gpio_set_mask (uint32_t mask) [inline], [static]`

**参数**

- `mask`: 要置位的 GPIO 值位掩码

#### gpio_set_mask64

#### gpio_set_mask_n

`static void gpio_set_mask_n (uint n, uint32_t mask) [inline], [static]`

将掩码中出现的所有 GPIO 驱动为高电平。

**参数**

- `n`: 要更新的掩码的 GPIO 起始编号。`n == 0` 表示 0→31，`n == 1` 表示 32→63，以此类推。
- `mask`: 32 个 GPIO 值的位掩码，表示要置位的位

#### gpio_set_pulls

`void gpio_set_pulls (uint gpio, bool up, bool down)`

设置指定 GPIO 的上拉和下拉。

**注意**：在 RP2040 上，同时使能上拉和下拉会启用“总线保持”功能，即把 GPIO 弱拉到它当前的高／低电平状态。

**参数**

- `gpio`: GPIO 编号
- `up`: 为 true 时对该 GPIO 设置上拉
- `down`: 为 true 时对该 GPIO 设置下拉

#### gpio_set_slew_rate

`void gpio_set_slew_rate (uint gpio, enum gpio_slew_rate slew)`
