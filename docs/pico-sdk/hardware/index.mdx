# Hardware APIs

本章包含以下 API 分组：

- [hardware_adc](./hardware-adc.mdx): 模数转换器（ADC）API。
- [hardware_base](./hardware-base.mdx): 内存映射硬件寄存器的底层类型与（原子）访问函数。
- [hardware_boot_lock](./hardware-boot-lock.mdx)
- [hardware_claim](./hardware-claim.mdx): 轻量级硬件资源管理 API。
- [hardware_clocks](./hardware-clocks.mdx): 时钟管理 API。
- [hardware_divider](./hardware-divider.mdx): RP2040 底层硬件除法器 API。非 RP2040 平台提供所有函数的软件实现版本。
- [hardware_dcp](./hardware-dcp.mdx) <span className="chip-tag rp2350">RP2350</span>: 双协处理器的汇编宏。
- [hardware_dma](./hardware-dma.mdx): DMA 控制器 API。
- [hardware_exception](./hardware-exception.mdx): 设置处理器异常处理函数的方法。
- [hardware_flash](./hardware-flash.mdx): 底层 flash 编程与擦除 API。
- [hardware_gpio](./hardware-gpio.mdx): 通用输入输出（GPIO）API。
- [hardware_hazard3](./hardware-hazard3.mdx) <span className="chip-tag rp2350">RP2350</span>: Hazard3 专用 RISC-V CSR 的访问函数，以及 Hazard3 自定义指令的内建函数。
- [hardware_i2c](./hardware-i2c.mdx): I2C 控制器 API。
- [hardware_interp](./hardware-interp.mdx): 硬件插值器 API。
- [hardware_irq](./hardware-irq.mdx): 硬件中断处理 API。
- [hardware_pio](./hardware-pio.mdx): 可编程 I/O（PIO）API。
- [hardware_pll](./hardware-pll.mdx): 锁相环（PLL）控制 API。
- [hardware_powman](./hardware-powman.mdx) <span className="chip-tag rp2350">RP2350</span>: 电源管理 API。
- [hardware_pwm](./hardware-pwm.mdx): 硬件脉宽调制（PWM）API。
- [hardware_psram](./hardware-psram.mdx) <span className="chip-tag rp2350">RP2350</span>: 底层 PSRAM 初始化函数。
- [hardware_resets](./hardware-resets.mdx): 硬件复位 API。
- [hardware_riscv](./hardware-riscv.mdx) <span className="chip-tag rp2350">RP2350</span>: 标准 RISC-V 硬件（主要是 CSR）的访问函数。
- [hardware_riscv_platform_timer](./hardware-riscv-platform-timer.mdx) <span className="chip-tag rp2350">RP2350</span>: 标准 RISC-V 平台定时器（mtime/mtimecmp）的访问函数，适用于搭载 RISC-V 处理器的 Raspberry Pi 微控制器。
- [hardware_rtc](./hardware-rtc.mdx) <span className="chip-tag rp2040">RP2040</span>: 硬件实时时钟（RTC）API。
- [hardware_rosc](./hardware-rosc.mdx): 环形振荡器（ROSC）API。
- [hardware_rcp](./hardware-rcp.mdx) <span className="chip-tag rp2350">RP2350</span>: 冗余协处理器的内联函数与汇编宏。
- [hardware_spi](./hardware-spi.mdx): 硬件 SPI API。
- [hardware_sha256](./hardware-sha256.mdx) <span className="chip-tag rp2350">RP2350</span>: 硬件 SHA-256 加速单元 API。
- [hardware_sync](./hardware-sync.mdx): 底层硬件自旋锁、屏障与处理器事件 API。
- [hardware_ticks](./hardware-ticks.mdx): 硬件时钟节拍（tick）API。
- [hardware_timer](./hardware-timer.mdx): 底层硬件定时器 API。
- [hardware_uart](./hardware-uart.mdx): 硬件 UART API。
- [hardware_vreg](./hardware-vreg.mdx): 电压调节 API。
- [hardware_watchdog](./hardware-watchdog.mdx): 硬件看门狗定时器 API。
- [hardware_xip_cache](./hardware-xip-cache.mdx): XIP 缓存的底层缓存维护操作。
- [hardware_xosc](./hardware-xosc.mdx): 晶振（XOSC）API。
