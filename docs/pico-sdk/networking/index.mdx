# Networking

本章包含以下 API 分组：

- [pico_btstack](./pico-btstack.mdx): BTstack 的集成/封装库（其文档见此处）。
- [pico_lwip](./pico-lwip.mdx): lwIP 的集成/封装库（其文档见此处）。
- [pico_cyw43_driver](./pico-cyw43-driver.mdx): 对底层 cyw43_driver 的封装，将其与 pico_async_context 集成以处理后台工作。
- [pico_cyw43_arch](./pico-cyw43-arch.mdx): 用于将 CYW43 驱动（Pico W 的无线功能）与 lwIP（TCP/IP 协议栈）集成到 SDK 中的架构。它通过 pico_async_context 提供后台支持。
